Recorded runs (ship speed): the key learns how your ship slows down, per ship, master mode and atmospheric density, and shows the distance and time it would need to stop if you released the throttle now. Press the key to start a recording, then release the throttle and let the ship stop; the run is saved when the speed reaches zero. Boosting, landing, accelerating again or pressing the key again discards the run (pressing while recording does not run the rule's press action). Record more runs, at different speeds and in atmosphere, to improve it; newer runs weigh more. Without a recorded run the key shows —, and a leading ~ marks an estimate beyond the recorded speeds or densities. Profiles are stored in %APPDATA%\SCStreamDeck\deceleration-profiles.json.
Live rate: assumes the value keeps dropping at the rate seen over the window: time = value / rate, units = value² / (2 × rate). For ship speed in m/s the units are meters. Without a clear reduction the key shows the Default look with —. Rules can test the estimate ("Estimate (units)" / "Estimate (time, s)") together with any other attributes.
