Press the key to switch the telemetry debug capture on or off. While it is on, raw frames of Star Citizen's telemetry stream are written (at most one every 2 seconds) to telemetry-debug.log, in the same folder as the plugin log. Switching it off adds a summary of the attributes the game never sent. Use it when an attribute does not show up: it lists fields the game sends that the protocol does not know, and fields the game leaves out (proto3 does not send a value of 0).
