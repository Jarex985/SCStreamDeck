Shows the elapsed time in minutes and tenths of a minute and the estimated distance (meters, then kilometers from 1 km) of the measurement started with the Travel Timer key. The values freeze when the measurement is stopped. The distance is estimated from the ship's speed, so it follows the path flown. The game's telemetry server must be enabled.
Label
Format templates (text color, background color, image and flash) and flags are created on the Config key; pick them per look below.
Display
The look of the key while it is available. Pressing the key only runs the press actions of this look.
Unavailable (first matching rule wins)
While any of these rules matches, the key takes the look of that rule and does nothing when pressed, so you can limit when it is shown and usable (for example only while you are seated). Without rules the key is always available.
