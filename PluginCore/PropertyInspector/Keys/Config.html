Flags
A flag is an on/off switch shared by the telemetry keys. A rule of an Advanced Telemetry Display can test it in its conditions and switch it when the rule becomes active, and a key can switch or toggle it when pressed. Use it for example as a master warning or to remember that the preflight check is done. Flag values are not saved: they return to their starting value when the plugin restarts.
Format templates
A template bundles text color, background color, image and flash. Pick it per rule on the telemetry keys; changing a template updates every rule that uses it.
