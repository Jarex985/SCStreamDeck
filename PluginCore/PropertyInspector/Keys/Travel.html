Press the key to start measuring the elapsed time and the estimated distance travelled (the speed is integrated over time), press again to stop: the values freeze. Pressing once more starts a new measurement. The key shows the values itself. Rules can test the state (Idle, Running, Stopped), the elapsed minutes and the distance in meters. The game's telemetry server must be enabled.
Label
Format templates (text color, background color, image and flash) and flags are created on the Config key; pick them per rule or look below.
Start
The look while no measurement was started yet. Pressing the key starts one.
Running
The look while a measurement is running, normally showing the elapsed time and the distance. Pressing the key stops it and freezes the values.
Stopped
The look while the frozen values of a stopped measurement are shown. Pressing the key starts a new measurement.
Unavailable (first matching rule wins)
While any of these rules matches, the key takes the look of that rule and does nothing when pressed, so you can limit when it is shown and usable (for example while the ship is moving or you are not seated). Without rules the key is always available.
